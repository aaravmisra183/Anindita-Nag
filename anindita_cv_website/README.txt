HOW TO VIEW
1. Keep the folder structure unchanged.
2. Open index.html in a browser.
3. Use the navigation links to move between pages.

HOW TO EDIT
- Edit the text in each HTML file.
- Change colours and layout in style.css.
- If the portrait does not display, put the correct image in images/ and update the img src in index.html.

PRIVACY NOTE
The public website intentionally leaves out the full home address, date of birth, gender and marital status. These details are not usually necessary on a public CV website. The phone number and email are included as supplied in the CV; publish them only with the CV owner's permission.

CONTENT NOTE
The site content is based on the supplied five-page CV PDF. Please verify job titles and dates before publishing. The CV lists Holiday Inn Express New Town from September 2026 to present.
